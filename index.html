Microprogramming foundations — read this before Section 1 5 min

The single shared bus

Every register (R0–Rn, PC, IR, MAR, MDR, TEMP, Y, Z) hangs off one internal CPU bus. Only one component may drive ("gate onto") that bus at a time — but many registers may listen and latch the value simultaneously.

Gating notation

RSIout, RAXin

out = this register drives the bus. in = this register reads the bus this cycle. A line can have one out and several ins.

The four basic micro-operations

  • Register Transfer — sourceout, destinationin
  • ALU Operation — operand(s) staged through Y, result lands in Z, then Zout, destinationin
  • Memory Fetch — addrout, MARin, Read, WMFC then MDRout, destinationin
  • Memory Store — addrout, MARin and dataout, MDRin, Write, WMFC

IR's two faces

IRAFout exposes the instruction's address field (a label/displacement baked into the instruction). IRDFout exposes its data field (an immediate value). The CU can always see IR's contents directly.

Fetch phase — identical for every instruction in this reviewer

1. PCout, MARin, Read, Select4, Add, Zin
2. Zout, PCin, WMFC
3. MDRout, IRin

Every card below starts numbering at line 4 — the execute phase — because lines 1–3 already happened, every single time, exactly like this. Every execute phase ends in END, which tells the CU to loop back and fetch the next instruction.
